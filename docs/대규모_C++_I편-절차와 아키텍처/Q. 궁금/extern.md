# extern
- 선언만 하고, 정의는 다른 곳에 있다.
- 한 파일의 전역변수를 공유하고자 할 때엔 꼭 필요함
- 함수는 기본적으로 extern 이라고 함


좋아요! **`extern` 키워드**는 C++에서 **심볼의 선언(Declaration)** 을 외부로 알리고, **정의(Definition)** 는 다른 곳에 있다고 명시할 때 사용합니다.
아래에 **구조적 설명 + 예제 + 상황별 차이**까지 정리해드릴게요.

---

## ✅ 1. `extern` 기본 개념

| 용어 | 의미                                       |
| -- | ---------------------------------------- |
| 선언 | **이 이름이 어딘가에 정의되어 있다**고 알리는 것 (`extern`) |
| 정의 | **실제 메모리 공간 / 코드**를 제공하는 것               |

### ➡️ extern은 선언만 하고, 정의는 다른 곳에 있다는 뜻입니다.

---

## ✅ 2. 변수 예제

### 📂 file1.cpp

```cpp
int count = 10;  // ✅ 정의 (Definition)
```

### 📂 file2.cpp

```cpp
#include <iostream>

extern int count;  // ✅ 선언 (Declaration), 정의는 다른 곳(file1.cpp)에 있음

int main() {
    std::cout << count << std::endl;  // 10 출력
}
```

### 🔍 해석

* `extern int count;` → "나는 count라는 변수가 있다는 것만 안다. 어디 있는지는 나중에 링커가 찾아줄 거야."
* 링커는 file1.o에서 count 정의를 찾고 연결합니다.

---

## ✅ 3. 함수 예제

### 📂 file1.cpp

```cpp
void hello() {         // ✅ 정의
    std::cout << "Hello!" << std::endl;
}
```

### 📂 file2.cpp

```cpp
extern void hello();   // ✅ 선언

int main() {
    hello();           // Hello! 출력
}
```

➡ 함수는 기본적으로 extern이지만, 명시해도 무방합니다.

---

## ✅ 4. 선언과 정의 구분 예시

| 코드              | 설명                         |
| --------------- | -------------------------- |
| `int x;`        | 외부 링키지 + 정의                |
| `extern int x;` | 외부 링키지 + 선언 (정의는 다른 곳)     |
| `static int x;` | 내부 링키지 + 정의 (다른 파일에서 안 보임) |

---

## ✅ 5. 왜 `extern`이 필요할까?

### 📌 모듈 분리

다른 파일에 있는 변수를 사용할 때 정의가 중복되지 않도록 하기 위해서.

### 📌 다중 번역 단위에서 안전하게 사용

모든 `.cpp`가 `int x = 1;`이라고 정의하면 **링커 에러 발생**
→ `extern`으로 선언만 하고, 정의는 딱 1곳에만 있어야 함.

---

## ✅ 6. 잘못된 예제 (링커 에러 발생)

```cpp
// file1.cpp
int data = 42;

// file2.cpp
int data = 42;  // ❌ multiple definition 에러 발생
```

✔️ 올바른 방법:

```cpp
// file1.cpp
int data = 42;

// file2.cpp
extern int data;
```

---

## ✅ 7. 특별한 경우: `extern "C"`

```cpp
extern "C" void cFunction();  // C 언어 방식으로 심볼 이름 내보내기
```

C++에서는 함수 이름이 `name mangling`되는데,
C 스타일의 extern으로 연결할 때 이 키워드를 사용합니다.
→ 보통 C 라이브러리 연결 시 필요

---

## ✅ 8. 한 줄 요약

> **`extern`은 "어딘가에 정의된 이름이 있어요"라고 컴파일러에게 알려주는 선언 키워드. 정의는 반드시 다른 곳에 있어야 하며, 링커가 연결한다.**

---

## ✅ 정리 도표

| 코드 예시               | 링키지      | 정의/선언 | 링커 역할             |
| ------------------- | -------- | ----- | ----------------- |
| `int x = 1;`        | External | 정의    | 링커가 다른 파일에서 참조 가능 |
| `extern int x;`     | External | 선언    | 정의를 찾아 연결         |
| `static int x = 1;` | Internal | 정의    | 링커 무시 (파일 내부 전용)  |


좋은 질문입니다!
C++에서 `extern`은 **꼭 필요한 경우가 있고, 안 써도 되는 경우가 있습니다.**
아래에 **꼭 사용해야 하는 경우와 그렇지 않은 경우를 구분**해서 명확하게 설명드릴게요.

---

## ✅ **1. 꼭 사용해야 하는 경우**

### ➤ 📄 다른 파일에서 **전역 변수**를 사용할 때

**함수는 기본이 extern이지만**,
**전역 변수는 명시적으로 extern을 써야 합니다!**

### 예시

#### file1.cpp

```cpp
int g_count = 10;  // ✅ 정의
```

#### file2.cpp

```cpp
extern int g_count;  // ✅ 꼭 필요!

void print() {
    std::cout << g_count << std::endl;
}
```

➡ 안 쓰고 그냥 `int g_count;` 하면 **“새로운 정의”가 되어 multiple definition 에러 발생**

---

### ➤ 이유:

* C++에서 변수는 기본적으로 **정의**로 간주됨 (`int g_count;` → 메모리 할당 발생)
* `extern int g_count;` 라고 해야 \*\*“정의는 다른 곳”\*\*이라는 뜻이 됩니다.

---

## ✅ **2. 사용하지 않아도 되는 경우**

### ➤ 함수의 경우

```cpp
void hello();  // 선언
```

➡ 함수는 기본적으로 **외부 링키지(external linkage)** → `extern` 없이도 다른 파일에서 참조 가능

이렇게 명시적으로 써도 의미는 같음:

```cpp
extern void hello();
```

---

## ✅ **3. 그 외 사용되는 경우 (특수)**

| 상황                | 사용 여부   | 설명                                 |
| ----------------- | ------- | ---------------------------------- |
| 다른 파일 전역 변수       | ✅ 필수    | 안 쓰면 multiple definition 에러        |
| 함수 선언             | ⛔ 생략 가능 | 기본 외부 링키지                          |
| `extern "C"`      | ✅ 필요    | C 함수와 연결 시 사용 (`name mangling` 방지) |
| `extern template` | ✅ 필요    | 템플릿 강제 인스턴스화 방지                    |

---

## ✅ **4. 꼭 사용해야 하는 대표적 상황 요약**

| 사용 예시                            | 꼭 필요 여부     |
| -------------------------------- | ----------- |
| 다른 파일의 전역 변수                     | ✅ 필요        |
| 다른 파일의 함수                        | ❌ 불필요 (기본값) |
| C와의 연결 (`extern "C"`)            | ✅ 필요        |
| 템플릿 인스턴스화 제어 (`extern template`) | ✅ 필요        |

---

## ✅ 한 줄 요약

> 📌 다른 파일의 **전역 변수**를 사용할 때는 **꼭 `extern`이 필요**,
> 📌 함수는 기본적으로 외부 링크라 필요 없음.
