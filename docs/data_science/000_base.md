## 모집단과 표본
- 모델링의 위해 사용하는 데이터는 모두 표본이다. 모집단은 수집할 수 없을정도로 매우크기때문에, 적당한 양의 데이터를 쓴다.
- 그러므로 표본으로부터 모집단의 성질을 추측하는 과정을 모델링으로 하는 것이다.

## 기호

1. $$ 정규화 : Z = \frac{X- \bar X}{\sigma} $$
    - 표준편차에 표준편차를 나눠 평균 : 0, 표준편차 :0 으로 만드는 것
1. $$ 예측치 : \hat x $$
    - 예측치
    - 모델에 독립변수를 넣었을 때 나온 결과 값

2. $$ 평균 : \bar X $$
    - 평균

3. $$ 편차 : X_i - \bar X$$
    - 기준(평균, $\bar X$) 으로부터  
    어느방향(+, -)으로 얼마나 떨어져 있는가

4. $$ 분산 : \frac{1}{n}\Sigma (X_i- \bar X)^2 $$
    - 이 데이터들이 기준으로 부터 얼마나 분포해 있는가의 대표값  
    분포의 정도이므로 방향이 필요없다 --> 제곱(또는 절대값)

5. $$ 공분산 : Cov(X,Y) = \frac{1}{n-1}\Sigma (X_i- \bar X)(Y_i- \bar Y) $$
    - 두 변수가 함께 어떻게 변하는 가를 나타내는 통계지표.
        - X와 Y는 서로 다른 데이터 '열'이다.
            - X : 질병, Y : 성별
    - n-1 의 의미
        1) 베셀의 보정 : 애초 표본은 모집단보다 편차가 작은 경우가 많다.(적절히 뭉친 데이터를 쓰니까)
        - 꼼수로 n보다 작은 n-1로 나누어 의도적으로 계산결과를 크게 만들어 과소평가되는 것을 줄이기 위함.
        2) n개에 대한 표본평균을 구하게 될 때, 마지막 한개의 데이터는 평균에 맞추어 딱 한개의 값으로 정해질 수 밖에 없다. 
            - 즉, n개에 대해 평균을 구하더라도, 나머지 하나 남은 것은 자유도를 잃은 것에 대한 반영이 n-1인 것
        3) 두 변수에 대한 것이므로 n >= 2부터여야한다는 직관도 틀리지 않다.
