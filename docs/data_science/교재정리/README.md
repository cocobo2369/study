# Level 2 Data Science 기본 교재 정리

원본: `(PC다운로드용) [Lv2] Data Science 기본 교재.pdf`

이 폴더는 원본의 1~23단원을 단원별 마크다운으로 재구성한 학습 노트다. 슬라이드 전체 캡처는 넣지 않았으며, 개념의 이해에 꼭 필요한 시각 자료만 별도 이미지로 추출한다.

PDF 3~611쪽(총 609쪽)을 페이지별로 다시 판독하고 단원 노트와 대조했다. 각 페이지의 판독·반영 여부는 [페이지 반영표](페이지_반영표.md)에서 확인할 수 있다. OCR 원문 대조본은 `_audit/chapters`에 보관하며, OCR 오류를 그대로 본문에 옮기지 않고 원본 문맥과 수식에 맞춰 교정했다.

## 읽는 법

- `교재 핵심`: 슬라이드의 주요 내용을 문장과 수식으로 재구성
- `보강`: 슬라이드만으로 놓치기 쉬운 해석·실무 주의점
- `체크포인트`: 시험이나 복습 때 확인할 항목
- `교재 확인문제`: 해당 단원 말미의 문제와 답·핵심 해설
- 각 파일의 페이지 표시는 PDF 뷰어 기준이며, 인쇄된 쪽 번호와 다를 수 있다.
