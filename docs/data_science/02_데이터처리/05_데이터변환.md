### 수치형 데이터 변환 
- 수치형의 문제
    - 단위 통일 -> 정규화(구간화, 표준화)
    - 너무 넓은 범위 -> 범주화
    - 비정규분포 -> 지수,로그,역 변환

#### 1. 정규화(Normalization)
- 단위통일!
1. 구간화(Min-Max scaling)
    - 구간이니 최대 최소에 대한 스케일링
    - 단위가 다른 변수들 비교에 씀
    - quantile 정규화
        - min : 0, max :1
    - (x-min)/(max-min)

2. 표준화(Standardization)
    - 단위가 다른 변수들 비교에 씀
    - 변환 전 정규분포 -> 변환 후 표준 정규분포
    - standard score
    - Z score
    - Z-value
    - 평균 : 0, 표준편차 :1
    - 평균을 빼고 표준편차로 나누면 됨

#### 2. Lp-norm
- norm : 벡터 길이(크기) 측정을 위한 함수
- L1-norm : 맨해튼 거리
    - 절대값의 합
- L2-norm : 유클라디안 거리
    - 제곱합의 루트
#### 3. 비정규분포 처리
- 비정규분포를 이룬다. = 치우쳐저있다.
    - positive skew : 쓸데 없는 큰 값들
        - 큰 값들을 줄이는 방향으로 변환 필요
    - negative skew : 쓸데 없는 작은 값들
        - 작은 값들은 키우는 방향으로 변환 필요
- 왜곡을 유발하는 값을 억제하여 정규화에 가깝게 만드는 방법
    - 지수, 로그, 역 변환

- 로그 변환 : 값을 줄인다. - positive skew 적합
    - 로그함수는 값이 커질수록 기울기가 줄어드니 큰 값을 억제한다.
- 지수 변환
    - 1 < 밑 : 값을 키운다. - negative skew 적합
    - 0 < 밑 < 1 : 값을 줄인다. - positive skew 적합
- 이런 의미로 가장 쉽게 먼저하는 것이 로그변환이다.
- 이후 다른 변환들을 수행해본다.

- positive skew -> 로그변환 -> normal 화
    - 즉 오른쪽으로 퍼진 것을 다시 당겨줌
    - 평균이 작아짐
        - 이게 맞지. 쓸데없는 값들로 평균이 뻥튀기 되었으니
- negative skew -> 지수변환 -> normal 화
    - 즉 왼쪽으로 퍼진 것을 다시 당겨줌
    - 평균이 커짐

| 분포 형태         | 꼬리 방향  | 적합한 변환    |
| ------------- | ------ | --------- |
| Positive Skew | 오른쪽 꼬리 | 로그, 역수 변환 |
| Negative Skew | 왼쪽 꼬리  |  지수 변환   |


#### 4. 범주화(discretization)
- 범위가 너무 넒어서 범위를 '범주화' 하여 관리
- 연령대, 등급
- Numeric(수치형) -> Categorical(범주형)
    - Nominal(명목형), Ordinal(순서형)
```python
cut()
```

### 범주형 데이터 변환 3개
- 이렇게 생각하면 쉽다.
- 데이터는 수치화해서 처리하면 쉽다.
- 그런데 범주형은 수치가 아니니 수치로 만들어보고 싶은 것!
- 가장 간단한게 구분할 수 있게 0,1,2,3,4 ... 로 한다. --> label
- 버튼처럼 0,1,0,0 으로 --> OHE
- 명목을 순서로!

#### 1. One-Hot-Encoding
- 해당 범주만 true, 나머지는 false로 만들기
- 범주가 N개 있다면 N*N 의 단위 행렬을 만드는 꼴임
- 다 false(0)으로 만들어버려 dummy coding이라고도함

|Category|Category_A|Category_B|Category_C|
|-|-|-|-|
|A|1|0|0|
|B|0|1|0|
|C|0|0|1|
