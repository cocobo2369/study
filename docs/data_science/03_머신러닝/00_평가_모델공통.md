## 모델 공통

### 가설함수 = 모델
- 학습 데이터에 없는 새로운 데이터를 넣어 예측값을 출력
- 모델을 의미
* 분류: $h_\theta(x) = \text{sigmoid}(wx + b)$ → 확률 출력
* 회귀: $h_\theta(x) = wx + b$ → 실수 출력

### 비용함수 = 오차
- 목적함수 : 가설함수의 오차를 줄이기 위한 목적이있는 함수라고도 함
- 결국 오차 출력임

### Holdout Test
- 과적합 방지
- 데이터 셋을 나눈다.
    - 학습 : 평가 = 7:3, 8:2
    - 학습 : 검증 : 평가 = 5:3:2

### 교차검증(Cross Validation)
-  **K-fold CV**
- 과적합 방지
- holdout의 활용
- 데이터 set 을 K 개로 나눠 학습데이터를 평가데이터로도 활용
- (학습 : K-1, 평가 : 1 ) * K 번 하여 평가 셋을 K개 만큼 만드는 효과
- K가 크면 느림
