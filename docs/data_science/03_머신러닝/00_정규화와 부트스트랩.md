## 정규화
- 거리 계산 시 편향 예방
- 학습데이터를 기반으로 평가 데이터를 정규화
- 학습데이터와 평가데이터를 한번에 정규화하지 않음

## 부트스트랩
- 복원 추출 허용 = 단순 임의 표본 추출
    - 학습데이터 크기가 커지는 효과
- 데이터 불균형에  사용
    -   종속변수의 불균형
    - undersampling
    - oversampling
- OOB(Out Of Bag)
    - 부트스트랩으로 추출되지 않은 데이터
    - 충분한 데이터 크기에서 36.8%가 추출되지 않음
    - 자연상수의 역수 값임
