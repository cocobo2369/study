## 민코프스키 거리
- p값 조절로 맨해튼, 유클리드, 체비쇼프 거리 모두 표현 가능
    - $$D(x, y) = \left( \sum_{i=1}^{n} |x_i - y_i|^p \right)^{\frac{1}{p}}$$
    | 기호     | 의미           |
    | ------ | ------------ |
    | $x, y$ | 두 벡터         |
    | $n$    | 차원 수         |
    | $p$    | 거리의 차수 (지수값) |


- 다양한 거리 계산을 한 공식으로 통합해서 사용 가능
- **KNN, K-means, 이상치 탐지 등**에서 유용
- 모델에 따라 성능이 **p값에 민감**할 수 있음 → 튜닝 필요
- p가 무한대가 되면 두 점 사이의 거리들 중 최대값이 됨
