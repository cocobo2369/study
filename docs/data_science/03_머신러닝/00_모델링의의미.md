# 📌 모델링한다
> 모델링 = **(함수) 와 (독립변수들의 선형결합)** 구조에서,
> 데이터를 가장 잘 설명하는 β를 찾는 과정

- **모델링한다** = 데이터를 가장 잘 설명하는 **β(계수)** 값을 찾는 과정
  - 우선 주어진 데이터들로 설명이 잘되는지를 확인한다.
- 독립변수 $x$들이 많아도, **가장 단순한 가정**은 **선형적 결합**

$$
z = \beta_0 + \beta_1 x_1 + \dots + \beta_k x_k
$$

- 여기에 **함수**(예: 시그모이드, ReLU, exp 등)를 씌워서 최종 예측값을 만듦
- 함수의 종류에 따라 **β의 의미와 값이 달라짐**

  * 시그모이드 → 로지스틱 회귀, 확률 예측
  * 항등함수 → 선형회귀
  * 기타 비선형 함수 → 다양한 회귀/분류 모델
