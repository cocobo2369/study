## 02-01 데이터 이해

### 요약

| 척도 종류               | 의미                     | 예시                    | 수학 연산 가능성         |
| ------------------- | ---------------------- | --------------------- | ----------------- |
| **Nominal** (명목척도)  | 이름 분류      | 성별, 혈액형, 도시, 색깔, 단순 숫자       | == 만 가능           |
| **Ordinal** (서열척도)  | 분류 + 순서         | 학점(A>B>C), 만족도(1\~5점) | ==, >, < 가능 (덧셈✖) |
| **Interval** (등간척도) | 분류 + 순서 + 간격 , **절대 0 없음** | 섭씨온도, 연도, IQ 점수       | 덧셈, 뺄셈 가능   |
| **Ratio** (비율척도)    | 분류 + 순서 + 간격 + 비율, **절대 0 있음**  | 키, 몸무게, 나이, 수입, 거리    | 모든 연산 가능          |

- 비율 가능  = 0이 수치적으로 없음 = ratio
- 비율 불가능 = 0이 상징적인 기준 = interval
- 비율이 의미가 있으려면 없음이 기준이 되어야 한다.
  - 이는 -의미가 없는 것이 비율의 의미를 지닐 수 있다고 볼 수 있다.
  - -10cm는 의미가 없다.
  - -10도는 의미가 있다.
  - 즉 0의 기준이 실제로 없음을 의미하는 게 raio이고, 상징적인 기준으로 사용되면 비율을 쓸 수 없는게 interval이다.

---

### 🔸 1️⃣ **Nominal Scale (명목 척도)**

- ✔️ 분류만 가능
- ❌ 순서 없음
- ❌ 수치 간 의미 없음

**📌 예시:**

- 성별: 남/여
- 혈액형: A, B, AB, O
- 색깔: 빨강, 파랑, 노랑
- 지역: 서울, 부산, 대구

**🎯 처리 방법:** One-hot encoding, Label encoding (순서 X)

---

### 🔸 2️⃣ **Ordinal Scale (서열 척도)**

- ✔️ 순서 O
- ❌ 간격은 불명확 (A와 B 사이 간격 ≠ B와 C 사이 간격)
- ❌ 평균, 덧셈 등의 계산 불가

**📌 예시:**

- 학점: A > B > C
- 만족도: 매우만족 > 만족 > 보통 > 불만족
- 계급: 병장 > 상병 > 일병 > 이등병

**🎯 처리 방법:** Label encoding
**주의:** 숫자라고 해서 간격 계산하면 안 됨!

---

### 🔸 3️⃣ **Interval Scale (등간 척도)**

- ✔️ 순서 O
- ✔️ 간격 O (10도와 20도의 차이 = 20도와 30도의 차이)
- ❌ 절대적 기준 0 없음 → 비율 계산 불가 (20도는 10도의 2배 ❌)

**📌 예시:**

- 섭씨 온도 (0도는 "없음"이 아님)
- 연도 (기원후 0년은 시간이 없는 상태가 아님)
- IQ 점수

**🎯 연산 가능:** 덧셈, 뺄셈
**비율 계산 불가:** “IQ 120은 IQ 60보다 2배 똑똑하다” ❌

---

### 🔸 4️⃣ **Ratio Scale (비율 척도)**

- ✔️ 순서 O
- ✔️ 간격 O
- ✔️ 절대적 0 O → **비율 의미 있음** (20kg은 10kg의 2배)

**📌 예시:**

- 키, 몸무게, 수입, 거리, 시간, 나이, 가격

**🎯 모든 연산 가능:** 덧셈, 뺄셈, 곱셈, 나눗셈

---

## ✅ 정리 요약표

| 척도       | 분류 | 순서 | 간격 | 비율 | 예시             | 연산 가능성        |
| -------- | -- | -- | -- | ---- | -------------- | ------------- |
| Nominal  | ✅| ❌  | ❌  | ❌    | 성별, 색깔, 혈액형    | 동등 비교 (==)    |
| Ordinal  | ✅| ✅  | ❌  | ❌    | 만족도, 등급, 학점    | 순서 비교 (>, <)  |
| Interval | ✅| ✅  | ✅  | ❌    | 온도(°C), 연도, IQ | 덧셈, 뺄셈, 0은 수치적으로 없음을 의미하지 않음        |
| Ratio    | ✅| ✅  | ✅  | ✅    | 키, 무게, 수입, 시간  | 모든 연산 (비율 포함), 0이 수치적으로 없음을 의미 |
