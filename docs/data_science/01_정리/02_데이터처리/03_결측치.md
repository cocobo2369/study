## 결측치

### ✅ 결측치(Missing Data)
- M = Missing
- AR = At Random
- 이니 MAR은 결측치라고만 생각하면 되고 C냐 N이냐만 구분하면 됨

- 결측치 처리
    - 삭제, 가장 쉬움
        - MCAR
    - 대치, 난이도 있음, 채워넣기
        - MAR : 평균등으로 넣기 쉬움
        - MNAR : 넣을 값을 고민해야함
        
| 종류       | 이름                           | 정의                                          | 결측 발생 원인     | 처리 난이도 | 📌 예시                                       | 📊 영향 / 처리 방법                                                                |
| -------- | ---------------------------- | ------------------------------------------- | ------------ | ------ | ------------------------------------------- | ---------------------------------------------------------------------------- |
| **MCAR** | Missing Completely At Random | 결측이 완전히 무작위로 발생하며 다른 변수들과 무관함               | 완전 랜덤        | 쉬움 ✅   | - 설문지 일부 페이지 인쇄 오류<br>- 센서가 일시적으로 고장나 측정 누락 | - 제거 -->  **편향 없음**<br>- `listwise deletion` 가능                            |
| **MAR**  | Missing At Random            | 결측이 다른 관측 변수와는 관련 있지만, **결측된 변수 값 자체와는 무관** | 다른 관측 변수에 의존 | 중간 ⚠️  | - 나이 많은 사람이 소득 응답 안 함<br>- 여성이 체중 응답을 꺼림    | - 관측 변수로 예측 <br>- 평균 대체, 회귀 대체, **다중 대체법(Multiple Imputation)**     |
| **MNAR** | Missing Not At Random        | 결측 발생이 **해당 변수 값 자체와 직접 관련** 있음             | 자기 자신 값에 의존  | 어려움 ❌  | - 소득이 높을수록 소득 응답 안 함<br>- 우울한 사람이 설문 중도 포기  | - 관측된 변수로 예측 **불가**<br>- **모델 기반 접근** (Tobit 회귀, EM 알고리즘)<br>- 전문가 도메인 지식 필요 |
