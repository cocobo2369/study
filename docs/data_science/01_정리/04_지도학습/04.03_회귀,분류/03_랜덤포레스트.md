# 랜덤포레스트 (Random Forest)

> 기본 교재 587~601페이지 정리

## 1. 랜덤포레스트 개요

랜덤포레스트는 **여러 개의 의사결정나무를 결합하여 예측 성능을 높이는 앙상블 학습 알고리즘**이다.

- 하나의 의사결정나무가 가진 한계를 여러 나무의 결과를 종합하여 보완한다.
- 각 나무는 서로 다른 부트스트랩 표본과 무작위로 선택된 일부 특성을 사용해 학습한다.
- 분류 문제에서는 **다수결 투표**, 회귀 문제에서는 **예측값의 평균**으로 최종 결과를 정한다.
- 단일 의사결정나무보다 일반적으로 성능과 안정성이 높지만, 모델의 해석은 더 어렵다.

### 관련 용어

#### 앙상블 학습 (Ensemble Learning)

여러 개의 약한 학습기(weak learner)를 결합하여 하나의 강한 학습기(strong learner)를 만드는 기법이다.

#### 배깅 (Bagging)

배깅은 **Bootstrap Aggregating**의 줄임말이다. 원본 데이터에서 복원추출로 여러 훈련 데이터셋을 만들고, 각 데이터셋으로 모델을 학습한 뒤 결과를 집계한다.

#### 특성 부분집합 선택 (Feature Subset Selection)

각 의사결정나무의 노드를 분할할 때 전체 특성을 모두 검토하지 않고, 무작위로 선택된 일부 특성만 사용한다. 이 과정은 나무 사이의 상관성을 낮추고 모델의 다양성을 높인다.

---

## 2. 목적과 특징

### 목적

- 단일 의사결정나무의 한계를 극복한다.
- 여러 나무의 결과를 결합하여 예측 성능과 안정성을 높인다.
- 개별 나무의 과적합 위험을 완화한다.

### 주요 특징

- 배깅과 무작위 특성 선택을 함께 사용하는 앙상블 방법이다.
- 여러 의사결정나무를 병렬로 학습할 수 있다.
- 분류는 다수결, 회귀는 평균으로 최종 예측값을 계산한다.
- 단일 의사결정나무보다 성능은 좋은 편이지만 해석은 더 어렵다.
- 각 특성이 불순도 감소에 기여한 정도를 이용하여 특성 중요도를 확인할 수 있다.

### 나무 수 증가에 따른 변화

- 연산 시간은 나무 개수에 비례하여 대체로 선형적으로 증가한다.
- 예측 속도는 느려지고 메모리 요구량은 증가한다.
- 초기에는 나무 수가 늘수록 성능이 빠르게 좋아지지만, 일정 개수 이상에서는 성능이 수렴한다.
- 나무가 충분히 많아지면 예측 결과가 안정되고 과적합 방지 효과도 커진다.

---

## 3. 활용 분야

- **제조**: 다변수 공정 조건 최적화
- **유통**: 수요 예측 및 재고 최적화
- **금융**: 여러 지표를 조합한 알고리즘 트레이딩

---

## 4. 의사결정나무의 기본 구조

- **루트 노드(root node)**: 나무의 가장 위에 있는 시작 노드
- **리프 노드(leaf node)**: 더 이상 분할되지 않는 말단 노드
- **부모 노드(parent node)**: 특정 노드 바로 위의 상위 노드
- **자식 노드(child node)**: 특정 노드에서 분기된 하위 노드
- **깊이(depth)**: 루트에서 해당 노드까지 내려간 간선의 수
- **단계(level)**: 교재의 예에서는 루트를 1단계로 보아, 첫 번째 자식 노드는 깊이 1·단계 2가 된다.

나무의 최대 깊이가 커지면 더 많은 규칙을 학습할 수 있지만 과적합 위험도 커진다.

---

## 5. 앙상블 모델링과 배깅

### 앙상블 모델링

다수의 기본 학습기를 조합하여 단일 모델보다 성능이 좋은 모델을 만드는 방법이다. 여러 알고리즘 또는 여러 개의 동일한 알고리즘을 결합해 예측·분류의 정확성과 안정성을 높인다.

앙상블 구성은 다음과 같이 구분할 수 있다.

- 하나의 데이터셋을 여러 모델에 학습
- 서로 다른 데이터셋을 각각의 모델에 학습
- 같은 종류의 모델 여러 개를 결합
- 서로 다른 종류의 모델을 결합

랜덤포레스트는 서로 다른 부트스트랩 표본을 여러 의사결정나무에 학습시키는 방식에 해당한다.

### 배깅의 동작

1. 원본 데이터에서 복원추출하여 여러 부트스트랩 훈련 데이터셋을 만든다.
2. 각 부트스트랩 데이터셋으로 기본 학습기를 독립적으로 학습한다.
3. 각 모델의 예측 결과를 집계한다.
4. 분류는 투표, 회귀는 산술평균을 이용해 최종 예측값을 구한다.

배깅의 주된 목적은 **분산 감소**이다. 분산이 큰 여러 기본 학습기의 결과를 평균하면 개별 모델보다 안정적인 예측을 얻을 수 있다.

## 6. 특성 중요도: MDI

**MDI(Mean Decrease in Impurity)**는 각 특성이 의사결정나무의 분할 과정에서 불순도를 얼마나 감소시켰는지를 기준으로 계산한 특성 중요도이다.

- 모델 학습 과정에서 자동으로 산출된다.
- 별도의 모델 재학습이나 데이터 조작 없이 구할 수 있다.
- 학습 데이터에 기반하여 계산한다.
- 정규화하면 모든 특성 중요도의 합은 1이 된다.
- 값이 클수록 해당 특성이 불순도 감소에 많이 기여했다는 의미다.

### 주의점

범주 수나 고유값이 많은 **고카디널리티 특성**은 중요도가 실제보다 크게 산출될 수 있다. 따라서 MDI만으로 특성의 실질적 중요성을 단정하지 않는 것이 좋다.

---

## 7. 랜덤포레스트의 학습과 예측

### 학습 과정

1. 원본 데이터에서 복원추출하여 $n$개의 부트스트랩 표본을 생성한다.
2. 각 나무에서 전체 특성 중 일부 특성만 무작위로 선택한다.
3. 각 부트스트랩 표본과 선택된 특성 부분집합으로 나무를 학습한다.
4. 학습한 $m$개의 나무를 결합하여 랜덤포레스트를 구성한다.

### 예측 과정

1. 각 나무가 새로운 데이터에 대해 개별 예측을 수행한다.
2. 개별 예측을 다음과 같이 집계한다.

   - **분류**: 다수결 투표로 최종 클래스를 결정
   - **회귀**: 모든 나무의 예측값을 평균하여 최종 값을 결정

---

## 8. 모델 성능 평가

### 분류 모델

혼동행렬의 각 항목은 다음과 같다.

- $TP$: 실제 양성을 양성으로 예측
- $TN$: 실제 음성을 음성으로 예측
- $FP$: 실제 음성을 양성으로 잘못 예측
- $FN$: 실제 양성을 음성으로 잘못 예측

#### 정확도 (Accuracy)

전체 예측 중 올바르게 예측한 비율이다.

$$
Accuracy = \frac{TP + TN}{TP + TN + FP + FN}
$$

#### 정밀도 (Precision)

양성으로 예측한 대상 중 실제 양성의 비율이다.

$$
Precision = \frac{TP}{TP + FP}
$$

#### 재현율 (Recall)

실제 양성 중 양성으로 올바르게 예측한 비율이다.

$$
Recall = \frac{TP}{TP + FN}
$$

#### F1 점수 (F1-score)

정밀도와 재현율의 조화평균이다.

$$
F1 = \frac{2}{\frac{1}{Recall} + \frac{1}{Precision}}
= 2 \times \frac{Precision \times Recall}{Precision + Recall}
$$

### 회귀 모델

$y_i$는 실제값, $\hat{y}_i$는 예측값, $y_i-\hat{y}_i$는 오차를 뜻한다.

#### 평균제곱오차 (MSE)

$$
MSE = \frac{1}{n}\sum_{i=1}^{n}(y_i-\hat{y}_i)^2
$$

오차를 제곱하므로 큰 오차에 더 큰 페널티를 준다.

#### 평균제곱근오차 (RMSE)

$$
RMSE = \sqrt{MSE}
= \sqrt{\frac{1}{n}\sum_{i=1}^{n}(y_i-\hat{y}_i)^2}
$$

MSE에 제곱근을 적용해 값의 단위를 종속변수와 같게 만든다.

#### 평균절대오차 (MAE)

$$
MAE = \frac{1}{n}\sum_{i=1}^{n}|y_i-\hat{y}_i|
$$

오차의 절댓값을 평균하므로 MSE보다 이상치의 영향이 작다.

#### 평균절대백분율오차 (MAPE)

$$
MAPE = \frac{1}{n}\sum_{i=1}^{n}\left|\frac{y_i-\hat{y}_i}{y_i}\right|\times100
$$

오차를 백분율로 표현해 해석하기 쉽지만, 실제값 $y_i$가 0이거나 0에 가까우면 사용할 때 주의해야 한다.

---

## 9. 과적합 방지 시 고려사항

- 나무 수가 지나치게 많으면 연산량과 메모리 사용량이 증가한다.
- 개별 나무의 **최대 깊이(max depth)**를 조절해 복잡도를 제한한다.
- 교차검증 등을 이용해 나무 수와 최대 깊이 같은 하이퍼파라미터를 사전에 검토한다.

---

## 핵심 요약

> 랜덤포레스트는 서로 다른 부트스트랩 표본과 무작위 특성 부분집합으로 여러 의사결정나무를 학습하고, 분류에서는 투표·회귀에서는 평균으로 결과를 결합하는 배깅 기반 앙상블 모델이다. 단일 나무보다 예측이 안정적이고 과적합에 강하지만, 계산량과 메모리 사용량이 크며 해석이 어렵다는 점을 함께 고려해야 한다.
