### ⭐️ `df[]` 안에 들어갈 수 있는 것 : 변수이름, boolean list

`df[]`는 안에 들어온 값의 **종류**에 따라 다르게 동작해.

| 사용법                   | 의미            |
| --------------------- | ------------- |
| `df["age"]`           | `"age"` 열 선택  |
| `df[["name", "age"]]` | 여러 열 선택       |
| `df[df["age"] > 20]`  | 조건에 맞는 행만 필터링 |

---

## 핵심 원리

```python
df["age"] > 20
```

이 코드는 조건문처럼 보이지만, 실제 결과는 **True/False 목록**이야.

```python
0     True
1    False
2     True
Name: age, dtype: bool
```

그래서 아래 코드는:

```python
df[df["age"] > 20]
```

사실상 이런 의미야:

```python
df[[True, False, True]]
```

즉, Pandas가 **True인 행만 남겨준다**는 뜻이야.

---

## 정리

```python
df["age"]
```

→ 열 선택

```python
df["age"] > 20
```

→ True/False 조건 결과 생성

```python
df[df["age"] > 20]
```

→ True인 행만 필터링

## 한 줄 요약

`df[]` 안에 조건이 들어가는 게 아니라,
**조건식의 결과인 True/False 목록이 들어가서 행 필터링이 되는 것**이야.
