# 📌 **Graph RAG의 수식 설명**
Graph RAG는 문서를 지식 그래프로 변환하여 검색하고, 이 정보를 활용하여 AI가 응답을 생성하는 과정에서 다양한 **수학적 모델과 확률 기반 접근법**을 사용합니다.

📌 **이번 설명에서는 문서에서 사용된 주요 수식의 의미를 하나씩 분석하고, 쉽게 이해할 수 있도록 설명하겠습니다.**

---

# 🔹 **1️⃣ Graph RAG의 기본 목표 수식**
Graph RAG의 목표는 **사용자의 질문(q)에 대해, 지식 그래프(G)를 활용하여 최적의 응답(a*)을 생성하는 것**입니다.

✅ **Graph RAG의 최적 응답을 구하는 공식:**
\[
a^* = \arg\max_{a \in A} p(a | q, G)
\]
**✅ 의미:**  
- **\( a^* \)**: 질문 **q**에 대한 최적의 답변  
- **\( p(a | q, G) \)**: 질문 **q**가 주어졌을 때, 지식 그래프 **G**를 참고하여 답변 **a**가 생성될 확률  
- **\( A \)**: 가능한 답변의 전체 집합  

👉 **즉, 질문 q가 주어지면, 지식 그래프 G에서 가장 높은 확률을 가진 답변 \( a^* \)을 선택하는 과정!**

---

# 🔹 **2️⃣ 검색기(Retriever) 수식**
Graph RAG에서 검색기(Retriever)는 질문(q)에 대해 **가장 관련성이 높은 지식 그래프의 부분(G*)을 선택**하는 역할을 합니다.

✅ **검색기의 목표: 최적의 서브그래프(G*) 선택**
\[
G^* = G\text{-Retriever}(q, G) = \arg\max_{G' \subseteq R(G)} p_{\theta}(G' | q, G)
\]
**✅ 의미:**  
- **\( G^* \)**: 질문(q)에 대한 최적의 서브그래프 (Graph RAG가 선택한 가장 중요한 부분)  
- **\( G' \subseteq G \)**: 전체 지식 그래프 G의 부분 집합 (서브그래프)  
- **\( p_{\theta}(G' | q, G) \)**: 질문(q)와 전체 그래프(G)가 주어졌을 때, 서브그래프 \( G' \)가 선택될 확률  
- **\( R(G) \)**: 전체 그래프 G에서 검색 가능한 서브그래프의 집합  

👉 **즉, Retriever는 전체 지식 그래프 G에서 "질문과 관련된 가장 적절한 서브그래프 G*"를 찾아내는 과정!**

---

# 🔹 **3️⃣ 생성기(Generator) 수식**
Graph RAG에서 생성기(Generator)는 검색기(Retriever)가 선택한 서브그래프(G*)를 활용하여 답변을 생성합니다.

✅ **생성기의 목표: 최적의 답변(a*) 생성**
\[
a^* = G\text{-Generator}(q, G^*) = \arg\max_{a \in A} p_{\phi}(a | q, G^*)
\]
**✅ 의미:**  
- **\( a^* \)**: 최적의 답변  
- **\( G^* \)**: 검색기가 선택한 최적의 서브그래프  
- **\( p_{\phi}(a | q, G^*) \)**: 질문(q)과 서브그래프(G*)가 주어졌을 때, 답변 a가 생성될 확률  

👉 **즉, 검색된 서브그래프(G*)를 바탕으로 가장 적절한 답변을 생성하는 과정!**

---

# 🔹 **4️⃣ 검색 최적화 (유사도 기반 검색)**
Graph RAG에서는 검색기(Retriever)가 **사용자의 질문(q)과 그래프(G) 내 요소들의 유사도를 계산**하여 최적의 서브그래프(G*)를 선택합니다.

✅ **유사도(Similarity) 기반 최적 서브그래프 선택**
\[
G^* = \arg\max_{G' \subseteq R(G)} \text{Sim}(q, G')
\]
**✅ 의미:**  
- **\( \text{Sim}(q, G') \)**: 질문(q)과 서브그래프(G') 간의 유사도 (예: 코사인 유사도, 임베딩 거리 등)  
- **\( G^* \)**: 가장 유사도가 높은 최적의 서브그래프  

👉 **즉, Graph RAG의 검색기는 질문과 가장 유사한 정보를 포함하는 서브그래프를 찾는 과정!**

---

# 🔹 **5️⃣ Graph Neural Networks(GNN) 기반 노드 업데이트 수식**
Graph RAG는 그래프 신경망(GNN)을 활용하여 **노드(Node)의 의미를 학습하고, 정보를 전파(Message Passing)하는 방식**을 사용합니다.

✅ **GNN에서 노드 업데이트 공식**
\[
h_i^{(l)} = \text{UPD} \left( h_i^{(l-1)}, \text{AGG}_{j \in N(i)} \text{MSG}(h_i^{(l-1)}, h_j^{(l-1)}, e_{i,j}^{(l-1)}) \right)
\]
**✅ 의미:**  
- **\( h_i^{(l)} \)**: 현재 노드(i)의 새로운 표현 벡터 (노드 속성)  
- **\( h_i^{(l-1)} \)**: 이전 단계의 노드 표현 벡터  
- **\( \text{N}(i) \)**: 노드 i의 이웃(Neighbor) 집합  
- **\( \text{MSG}(h_i, h_j, e_{i,j}) \)**: 노드 i와 노드 j 간의 메시지 전달 함수  
- **\( \text{AGG} \)**: 여러 이웃 노드에서 받은 메시지를 하나로 합치는 함수 (예: 평균, 합, 최대)  
- **\( \text{UPD} \)**: 노드의 속성을 업데이트하는 함수  

👉 **즉, GNN은 그래프에서 "노드 간의 관계를 학습하여 정보를 전달하고, 더 나은 표현 벡터를 계산하는 과정!"**

---

# 🔹 **6️⃣ Retrieval Paradigm (검색 방식)**
Graph RAG의 검색기(Retriever)는 다양한 검색 전략을 활용할 수 있습니다.

✅ **1. 단일 검색(Once Retrieval)**  
한 번의 검색 과정에서 모든 정보를 가져옴  
\[
G^* = \text{Retriever}(q, G)
\]
✅ **2. 반복 검색(Iterative Retrieval)**  
이전 검색 결과를 바탕으로 추가 검색을 수행  
\[
G^{(t+1)} = \text{Retriever}(q, G^{(t)})
\]
✅ **3. 다단계 검색(Multi-stage Retrieval)**  
여러 단계를 거쳐 점진적으로 검색 범위를 좁힘  
\[
G^*_1 \to G^*_2 \to G^*_3
\]

👉 **즉, Graph RAG는 단순 검색이 아니라, 상황에 따라 적절한 검색 방식을 선택하여 더 정확한 결과를 찾음!**
