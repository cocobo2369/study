### **📌 UV 분해(Matrix Factorization)는 왜 선형적인 관계만 학습 가능할까?**  

UV 분해(행렬 분해, **Matrix Factorization, MF**)는 다음과 같은 식을 기반으로 합니다.

\[
R \approx U V^T
\]

즉, 사용자 벡터 \( U_u \) 와 아이템 벡터 \( V_i \) 간의 내적(inner product)으로 예측 평점 \( \hat{r}_{ui} \)을 계산합니다.

\[
\hat{r}_{ui} = U_u \cdot V_i^T
\]

이제, **왜 이것이 선형적인 관계만 학습 가능한지** 알아봅시다.

---

## **📖 1️⃣ UV 분해는 선형 변환만 포함**
UV 분해에서 예측 값은 **사용자 벡터 \( U_u \) 와 아이템 벡터 \( V_i \) 의 단순한 선형 조합**으로 결정됩니다.  

### **✅ 행렬 곱은 기본적으로 선형 연산**
\[
\hat{r}_{ui} = u_1 v_1 + u_2 v_2 + ... + u_k v_k
\]

이 식을 보면, **각 요소들이 단순한 곱셈과 덧셈으로만 결합**되어 있습니다.  
즉, **비선형적인 관계(예: 곡선 형태의 관계)를 표현할 수 없음** → **결과적으로 선형적인 패턴만 학습 가능**합니다.

---

## **📖 2️⃣ UV 분해의 한계: 비선형 관계를 학습할 수 없음**
### **예제: 사용자의 영화 선호 패턴**
사용자가 선호하는 영화가 특정 **비선형적인 관계**를 가진다고 가정해 보겠습니다.

#### **(1) 선형적인 취향 패턴**
- 사용자가 "코미디 영화"를 좋아하면, "로맨틱 코미디"도 어느 정도 좋아할 가능성이 있음  
- 이런 경우는 **선형적인 관계**로 표현 가능 → **UV 분해가 적절함**

#### **(2) 비선형적인 취향 패턴**
- 사용자가 "SF 영화"와 "로맨틱 코미디"를 둘 다 좋아하지만, "액션 영화"는 극도로 싫어한다면?  
- 즉, 선호 패턴이 단순한 직선 관계가 아니라 복잡한 곡선 형태라면?  
  → **이런 경우는 선형 모델인 UV 분해로 정확한 패턴을 학습하기 어려움!**

---

## **📖 3️⃣ 비선형성을 반영하려면?**
### **✅ Neural Collaborative Filtering (NCF)**
UV 분해는 선형 관계만 학습 가능하므로, **비선형 관계를 반영하기 위해 신경망을 활용하는 방법**이 등장합니다.  
**NCF(Neural Collaborative Filtering)**은 다음과 같이 동작합니다.

1️⃣ **기본적으로 UV 분해처럼 사용자와 아이템을 벡터로 변환**  
2️⃣ **MLP (Multi-Layer Perceptron, 다층 신경망) 사용**  
   - 비선형 활성화 함수(ReLU, Sigmoid 등)를 추가하여 비선형적인 관계까지 학습 가능  
3️⃣ **선형 내적 대신 더 복잡한 패턴을 학습하여 추천 성능 향상**

### **📌 NCF의 핵심 아이디어**
\[
\hat{r}_{ui} = f(U_u, V_i)
\]

여기서 \( f \)는 신경망(MLP)으로 학습된 **비선형 함수**입니다.  
즉, 단순한 내적이 아니라 신경망이 데이터에서 **복잡한 패턴을 자동으로 학습**하여 추천 품질을 향상시킵니다.

---

## **📖 4️⃣ 결론**
### **✅ UV 분해는 선형적인 관계만 학습 가능한 이유**
1️⃣ **행렬 곱셈이 기본적으로 선형 연산이기 때문**  
   - \( \hat{r}_{ui} = U_u \cdot V_i^T \) 는 단순한 내적(inner product)  
2️⃣ **비선형 변환(예: 활성화 함수 ReLU, Sigmoid 등)이 포함되지 않음**  
3️⃣ **따라서 복잡한 비선형적인 취향을 표현할 수 없음**  

📌 **즉, UV 분해는 직선적인(선형적인) 관계를 학습하는 데는 좋지만, 비선형적인 관계를 학습하는 데 한계가 있음!**  
📌 **이를 해결하기 위해 Neural Collaborative Filtering(NCF) 같은 비선형 모델이 필요함!** 🚀
